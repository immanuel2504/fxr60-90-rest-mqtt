Once any app-led PUT has been made, the endpoint reports NON_DEFAULT thereafter.
"off" turns the LED off but still counts as an application-set state, and there
is no documented way back to DEFAULT through this endpoint. The reader was left
NON_DEFAULT at the end of testing for exactly this reason.
