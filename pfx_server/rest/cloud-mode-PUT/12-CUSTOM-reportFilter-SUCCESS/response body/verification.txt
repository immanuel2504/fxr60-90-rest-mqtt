*** reportFilter vs INVENTORY interval - two knobs, same effect ***

                              mechanism                     tested in
  modeSpecificSettings        INVENTORY mode only           test 04
    .interval
  reportFilter.duration       any mode (CUSTOM here)        this test

Both suppress repeat reports of the same tag for a configured period, and both
were measured doing so. The difference is availability: interval is only valid
inside INVENTORY mode's modeSpecificSettings, while reportFilter is a top-level
field usable in CUSTOM.
