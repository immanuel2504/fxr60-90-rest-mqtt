*** KEY FINDING - SIMPLE MODE STRIPS TAG METADATA ***

Fields present on every tag event in this mode:

    eventNum, format, idHex

That is all. No peakRssi, no antenna, no channel, no phase - even though the
reader was reporting all of those minutes earlier in its original CUSTOM mode.

SIMPLE mode accepts no tagMetaData key at all (it is not in the example, and the
mode is documented as a baseline), so there is no way to ask for more. If an
integration needs RSSI or antenna number, SIMPLE mode cannot provide it - use
INVENTORY, CONVEYOR or CUSTOM.

This is worth documenting explicitly: "SIMPLE" reads as "simple to configure",
but its real consequence is a reduced data payload.

Note the unique-tag count rose from 8 (baseline, 17 dBm) to 23
here at 30 dBm - the extra power pulled in tags outside the original read range.
That is expected, and it is why power is held at 30 for every subsequent test so
the counts stay comparable.
