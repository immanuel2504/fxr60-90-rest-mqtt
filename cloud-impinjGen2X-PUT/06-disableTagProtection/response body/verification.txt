This is the documented reversal of enableTagProtection and takes the same three
required fields (action, password, tagID).

*** ALWAYS RUN THIS BEFORE CLEARING THE PASSWORD ***

Order matters for cleanup. If a tag really were protected and you zeroed its
access password first, you would no longer be able to supply the password needed
to unprotect it - the tag would be permanently RF-silent to any reader that does
not know the old password. So:

    1. disableTagProtection  (with the current password)
    2. apply via start
    3. only then WRITE 00000000 back to RESERVED words 2-3

That is the order used here. Full cleanup, verified by reading RESERVED back on
all three tags:
