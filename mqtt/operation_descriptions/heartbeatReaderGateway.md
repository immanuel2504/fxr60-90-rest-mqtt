## Description

The `reader_gateway` section gives Reader Gateway heartbeat information, such as CPU usage, RAM usage, uptime, connection status, management-event counts, error counts, warning counts, and data-path statistics.

This section includes:

- CPU, RAM, and uptime for the Reader Gateway process.
- Control, data, management, and management-event connection status.
- Number of management events sent to the cloud.
- Error and warning counts generated by Reader Gateway.
- Data-message counts, retained-message counts, dropped-message counts, and queue depth.

Use this section to:

- Check whether cloud and MQTT endpoints are connected.
- Monitor Reader Gateway process health over time.
- Track how many management events the reader has published.
- Review data-path message counters and dropped-message counts.

## Event Details

| Property | Value |
|---|---|
| MQTT event | `heartbeat` |
| Heartbeat section | `data.reader_gateway` |
| Envelope `type` | `heartbeat` |
| Configuration path | `READER-GATEWAY.managementEventConfig.heartbeat.fields.reader_gateway` |
| Configure using MQTT | `set_config` |
| Configure using REST | `PUT /cloud/config` |
| Delivery destination | `endpointConfig.management.event` |
| Applies to | FXR60 / FXR90 |

## Configure Reader Gateway Fields

Set the management-event destination and heartbeat interval on the **Heartbeat** page.

To include Reader Gateway fields in the heartbeat payload, use `set_config` and add the required field names under:

```text
READER-GATEWAY.managementEventConfig.heartbeat.fields.reader_gateway
```

Fields not listed in the `reader_gateway` array are omitted from the published heartbeat payload.

Choose **MQTT — set_config** or **REST — PUT /cloud/config** from the **Example** dropdown in **Configuration Examples** below.

## Parameters

| Field | Description | Default |
|---|---|---|
| `NUM_DATA_MESSAGES_RXED` | Number of data messages received on the data path. | Enabled |
| `NUM_MANAGEMENT_EVENTS_TXED` | Number of management events sent to the cloud. | Enabled |
| `NUM_DATA_MESSAGES_TXED` | Number of data messages sent on the data path. | Enabled |
| `NUM_DATA_MESSAGES_RETAINED` | Number of data messages retained on the data path. | Enabled |
| `NUM_DATA_MESSAGES_DROPPED` | Number of data messages dropped on the data path. | Enabled |
| `CPU` | Reader Gateway process CPU utilisation. | Enabled |
| `RAM` | Reader Gateway process RAM utilisation. | Enabled |
| `UPTIME` | Reader Gateway process uptime. | Enabled |
| `NUM_ERRORS` | Number of errors generated by Reader Gateway. | Enabled |
| `NUM_WARNINGS` | Number of warnings generated by Reader Gateway. | Enabled |
| `INTERFACE_CONNECTION_STATUS` | Connection status for configured control, data, management, and management-event endpoints. | Enabled |
| `NOLOCKQ_DEPTH` | Reader Gateway no-lock queue depth. | Enabled |
