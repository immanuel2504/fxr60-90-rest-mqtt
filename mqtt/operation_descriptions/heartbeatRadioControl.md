## Description

The `radio_control` section gives Radio Control heartbeat information, such as status, CPU usage, RAM usage, uptime, antenna state, radio activity, radio connection status, errors, warnings, tag-read statistics, and radio packet counts.

This section includes:

- Antenna connection status for each reader port.
- Radio connection status and current inventory activity.
- CPU usage, RAM usage, and uptime for the Radio Control process.
- Error and warning counts generated by Radio Control.
- Total tag reads, per-antenna tag reads, and radio packet counts.

Use this section to:

- Confirm that the expected antenna ports are connected.
- Check whether inventory is active or inactive.
- Monitor Radio Control health over time.
- Track total tag reads and per-antenna read counts.

## Event Details

| Property | Value |
|---|---|
| MQTT event | `heartbeat` |
| Heartbeat section | `data.radio_control` |
| Envelope `type` | `heartbeat` |
| Configuration path | `READER-GATEWAY.managementEventConfig.heartbeat.fields.radio_control` |
| Configure using MQTT | `set_config` |
| Configure using REST | `PUT /cloud/config` |
| Delivery destination | `endpointConfig.management.event` |
| Applies to | FXR60 / FXR90 |

## Configure Radio Control Fields

Set the management-event destination and heartbeat interval on the **Heartbeat** page.

To include Radio Control fields in the heartbeat payload, use `set_config` and add the required field names under:

```text
READER-GATEWAY.managementEventConfig.heartbeat.fields.radio_control
```

Fields not listed in the `radio_control` array are omitted from the published heartbeat payload.

Choose **MQTT — set_config** or **REST — PUT /cloud/config** from the **Example** dropdown in **Configuration Examples** below.

## Parameters

| Field | Description | Default |
|---|---|---|
| `ANTENNAS` | Antenna connection status for each reader port. | Enabled |
| `RADIO_ACTIVITY` | Current inventory state. Example: `active`, `inactive`, or `unknown`. | Enabled |
| `RADIO_CONNECTION` | Current radio connection status. Example: `connected` or `disconnected`. | Enabled |
| `CPU` | Radio Control process CPU utilisation, from 0 to 100. | Enabled |
| `RAM` | Radio Control process RAM utilisation, from 0 to 100. | Enabled |
| `UPTIME` | Radio Control process uptime. | Enabled |
| `NUM_ERRORS` | Number of errors generated by Radio Control. | Enabled |
| `NUM_WARNINGS` | Number of warnings generated by Radio Control. | Enabled |
| `NUM_TAG_READS` | Total number of tags read. | Enabled |
| `NUM_TAG_READS_PER_ANTENNA` | Number of tags read per antenna. | Enabled |
| `NUM_DATA_MESSAGES_TXED` | Number of tag data messages transmitted. | Enabled |
| `NUM_RADIO_PACKETS_RXED` | Number of radio packets received. | Enabled |
| `STATUS` | Radio Control running status. | Enabled |
