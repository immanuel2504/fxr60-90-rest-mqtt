# `refresh-cert`

REST: `PUT /cloud/certificates/{certname}` → `cloud-certificates-certname/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/refresh_client_certificate.json` | request | `refresh_client_certificate` | Refresh named client certificate |
| `request/refresh_server_certificate.json` | request | `refresh_server_certificate` | Refresh named server certificate |
| `request/refresh_client_by_type.json` | request | `refresh_client_by_type` | Refresh client certificate by type |
| `request/refresh_server_by_type.json` | request | `refresh_server_by_type` | Refresh server certificate by type |
| `response/success.json` | response | `success` | Command succeeded |
