# `set_bleConfig`

REST: `PUT /cloud/bleConfig` → `cloud-bleconfig/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/disable_ble.json` | request | `disable_ble` | Disable BLE |
| `request/enable_ble.json` | request | `enable_ble` | Enable BLE |
| `request/enable_ble_with_interval.json` | request | `enable_ble_with_interval` | Enable BLE with scan interval |
| `request/enable_all_protocols.json` | request | `enable_all_protocols` | Enable all BLE protocols |
| `request/enable_ble_with_rssi_filter.json` | request | `enable_ble_with_rssi_filter` | Enable BLE with RSSI filter |
| `response/success.json` | response | `success` | Command succeeded |
