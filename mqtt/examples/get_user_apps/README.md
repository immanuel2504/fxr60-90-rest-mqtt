# `get_user_apps`

REST: `GET /cloud/apps` → `cloud-apps/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/get_installed_apps.json` | request | `get_installed_apps` | Get installed apps |
| `response/none_installed.json` | response | `none_installed` | No user applications |
| `response/installed_apps.json` | response | `installed_apps` | Installed apps |
