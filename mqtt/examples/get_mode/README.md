# `get_mode`

REST: `GET /cloud/mode` → `cloud-mode/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/verbose_false.json` | request | `verbose_false` | Configured values only |
| `request/verbose_true.json` | request | `verbose_true` | Full configuration including defaults |
| `response/verbose_false.json` | response | `verbose_false` | CUSTOM — configured values only |
| `response/verbose_true.json` | response | `verbose_true` | INVENTORY — full configuration |
| `response/SIMPLE.json` | response | `SIMPLE` | SIMPLE mode |
| `response/INVENTORY.json` | response | `INVENTORY` | INVENTORY mode |
| `response/PORTAL.json` | response | `PORTAL` | PORTAL mode |
| `response/CONVEYOR.json` | response | `CONVEYOR` | CONVEYOR mode |
