# `autostart_user_app`

REST: `PUT /cloud/apps/{appname}/autostart` → `cloud-apps-appname-autostart/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/autostart_true.json` | request | `autostart_true` | Autostart true |
| `request/autostart_false.json` | request | `autostart_false` | Autostart false |
| `response/success.json` | response | `success` | Command succeeded |
