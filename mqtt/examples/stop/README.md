# `stop`

REST: `PUT /cloud/stop` → `cloud-stop/`

| File | Direction | Example name | Summary title |
|---|---|---|---|
| `request/stop_RFID.json` | request | `stop_RFID` | Stop RFID |
| `request/stop_RFID_explicit.json` | request | `stop_RFID_explicit` | Stop RFID explicitly |
| `request/stop_BLE_only.json` | request | `stop_BLE_only` | Stop BLE only |
| `request/stop_BLE_and_RFID.json` | request | `stop_BLE_and_RFID` | Stop BLE and RFID |
| `response/success.json` | response | `success` | Command succeeded |
