# `/cloud/updatePassword`

- **PUT** — Changes the `admin` or `rfidadm` login password (`set_password`).

## PUT examples

| File | Direction | Example name | Summary |
|---|---|---|---|
| `PUT/set_password.json` | request | `set_password` | Set admin password |
| `PUT/set_password_rfidadm.json` | request | `set_password_rfidadm` | Set rfidadm password |
