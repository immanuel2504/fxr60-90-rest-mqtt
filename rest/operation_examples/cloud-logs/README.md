# `cloud-logs`

| File | Example name | Summary |
|---|---|---|
| `GET/info_packet_off.json` | `info_packet_off` | radio_control INFO, reader_gateway INFO, radioPacketLog off |
| `PUT/rg_debug_packet_on.json` | `rg_debug_packet_on` | reader_gateway DEBUG and radioPacketLog on |
| `PUT/radio_packet_log_on.json` | `radio_packet_log_on` | Enable radioPacketLog |
| `PUT/success.json` | `success` | Empty string on success |
