4. Sending uap0 with enable: true while mlan0 is connected drops the Wi-Fi client connection, and vice versa. This isn't true. When mlan0 is connected and we send uap0 set API with enable as true then we get an error message: 

	{  "code": 3,  "message": "CS:'setNetworkInfoReq' failed,Reason: Disable WiFi to enable Hotspot"}

	Same in the vice versa scenario as well 
	 
	If the reader's only route to your network is mlan0, enabling the hotspot will disconnect it. This line also has to be removed, because this isnt the correct working situation.
	
	The right description would be: if hotspot needs to be enabled then disable mlan0 first, and vice versa.
